# Technology Stack: Cyberpunk Tech Portfolio

## Core Frameworks
- **Next.js (App Router):** Powering the overall architecture, routing, and server-side optimizations.
- **React 19:** Utilizing the latest React features and optimizations.

## Immersive & 3D Systems
- **Three.js:** The foundational engine for all 3D rendering.
- **React Three Fiber (@react-three/fiber):** The React reconciler for Three.js.
- **Drei (@react-three/drei):** Specialized helpers and abstractions for Fiber.
- **Motion (framer-motion):** Powering high-performance UI animations and glitch effects.

## Styling & Layout
- **Tailwind CSS 4:** Modern, high-performance utility-first styling.
- **Arwes (Inspiration/Pattern):** Design patterns for high-tech, futuristic interfaces (animated SVG frames, HUDs).

## Asset & Media Management
- **Cloudinary:** Cloud-based storage and optimization for high-fidelity assets.
- **Next-Cloudinary:** Integration for optimized image and video delivery in Next.js.

## Developer Experience & Tooling
- **TypeScript:** Ensuring type safety across the complex UI and 3D systems.
- **Biome:** Fast, all-in-one tool for linting and formatting.
- **Lucide React:** Iconography suite for UI accents.

## Typography
- **Unbounded:** Primary display font for high-impact headers.
- **Departure Mono:** Code and technical HUD display.
- **Geist:** Clean sans-serif for long-form content and UI text.
