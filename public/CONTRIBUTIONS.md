### 3. Big Data Final Project: Steam Spam/Bot Review Detection System
*   **Role:** Lead Developer / System Architect
*   **Project Overview:** This project addresses the challenge of review manipulation on the Steam platform. It processes millions of records through a sophisticated Big Data pipeline to identify non-authentic reviews, helping maintain platform integrity and providing users with more reliable game ratings.
*   **Project Goal:** Developed a hybrid (streaming + batch) big data pipeline to detect gaming review manipulations (spam, bot reviews, review bombing) on the Steam platform.
*   **Tech Stack:** Kafka, MinIO, PySpark, Hive Metastore, Trino, FastAPI, Streamlit, BERT, Docker.
*   **Key Contributions:**
    *   **Hybrid Architecture Design:** Architected a complete data lakehouse system integrating real-time ingestion (Kafka) with batch preprocessing (PySpark) and distributed SQL querying (Trino).
    *   **Streaming & Ingestion:** Developed Kafka producers/consumers for real-time ingestion of 6.4M+ reviews, implementing a raw/clean layer storage strategy in MinIO.
    *   **Advanced ML Pipeline:**
        *   **Phase 1 (Unsupervised Labeling):** Engineered an ensemble anomaly detection system using **Isolation Forest** and **K-Means clustering** to auto-label suspicious reviews without manual annotation.
        *   **Phase 2 (Hybrid BERT Classifier):** Built an `EnhancedBERTClassifier` that fuses BERT contextual embeddings with engineered linguistic features (writing style analysis) to predict spam probability with high confidence.
    *   **API & Visualization:** Developed a **FastAPI** backend for serving model inference and a **Streamlit/React** dashboard for real-time visualization of detected spam patterns across games.
    *   **Orchestration & Automation:** Created an automated orchestration script (`run_all.sh`) to synchronize the deployment and execution of 9+ containerized services including Zookeeper, Kafka, Spark, and Hive.
